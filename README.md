# Práctica de Derecho Privado y Comercial

Página estática para practicar 64 preguntas de opción múltiple. No requiere instalación ni servidor: abrir `index.html` alcanza para usarla localmente.

La página permite realizar bloques de 10, 20 o las 64 preguntas, con orden aleatorio de preguntas y opciones, corrección inmediata y la respuesta desarrollada completa para estudiar después de cada elección.
